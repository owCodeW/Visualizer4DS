# Redis 7 底层数据结构可视化学习平台
## 最终确定方案：前端网页 + Python FastAPI 后端

我严格按照你想要的**学习 Redis7 底层数据结构**的目标，采用 **FastAPI 后端 + 前端交互网页** 实现，前后端分离、可运行、可扩展。

下面是**最终确认版设计**，不含代码，代码我会在下一条消息一次性全部给你。

---

## 一、项目整体介绍
### 1. 项目名称
**Redis7 DataStructure Visualizer**（Redis7 数据结构可视化学习工具）

### 2. 核心目标
- 可视化展示 Redis7 所有 value 类型的**底层数据结构**
- 前端网页：交互式动画 + 源码结构体一一对应
- 后端 Python：模拟 Redis 真实结构行为（增删改查、自动转换、分裂、合并）
- 你可以**点击按钮操作**，直观看到结构变化

### 3. 技术栈
- 前端：HTML + CSS + JS（纯原生，无框架）
- 后端：Python 3.8+ + **FastAPI**
- 通信：REST API + JSON
- 结构：前后端分离

---

## 二、支持展示的 Redis7 结构
1. **String → SDS 7.0**
2. **List → Quicklist（双向链表+Listpack）**
3. **Hash → Listpack / Hash Table**
4. **Set → Intset / Hash Table**
5. **ZSet → Listpack / Skiplist**
6. 后续可无限扩展

每个结构都会展示：
- C 语言源码结构体
- 内存逻辑视图
- 字段含义
- 操作行为
- 自动转换规则

---

## 三、系统架构设计
### 1. 架构图
```
前端网页（浏览器）
      ↑ ↓ API 请求
FastAPI 后端（Python）
      ↑ ↓
结构模拟引擎（Python 类模拟 Redis 真实结构）
```

### 2. 后端模块划分
1. **main.py**：FastAPI 入口、路由注册
2. **api/**：接口层（提供操作、获取结构、重置）
3. **structures/**：结构模拟层
   - SDS
   - QuickList
   - Listpack
   - ZipList
   - SkipList
   - HashTable
   - IntSet
4. **models/**：数据返回格式统一
5. **utils/**：日志、工具函数

### 3. 前端模块
1. **index.html**：结构选择首页
2. **pages/**：每个结构独立页面
3. **static/**：样式、交互逻辑、动画
4. **api.js**：与后端通信

---

## 四、功能流程设计
1. 打开网页 → 选择要学习的结构（如 Quicklist）
2. 前端请求后端 → 获取初始化结构数据
3. 页面自动渲染：
   - 左侧：Redis 源码结构体
   - 中间：交互式可视化视图
   - 右侧：知识点说明
4. 你点击按钮（LPUSH / RPUSH / HSET 等）
5. 前端发送操作 → 后端执行真实逻辑
6. 后端返回最新结构 → 前端自动更新视图 + 动画
